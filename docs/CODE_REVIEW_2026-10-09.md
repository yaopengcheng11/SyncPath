**审查发现**

1. **[P1] 撤销删除会把卡片恢复到另一个任务。**

   位置：[AppV2.tsx](../apps/web/src/AppV2.tsx#L571)，关联 571–578、605–626 行。

   撤销记录没有原任务 ID，执行时使用当前选中的任务。在任务 A 删除卡片，切换到可编辑任务 B，再撤销，会实际执行 `createEntry('B', A 的卡片内容)`。A 的删除没有被恢复，私有内容还可能出现在 B 的团队中。建议按任务保存撤销记录，并在执行时核验原任务。

   证据：从实际回调源码提取并执行的模拟复现，输出包含 `createEntry('B', { title: 'Private A card', ... })`。

2. **[P1] 应用剪贴板在退出账户后保留私有内容。**

   位置：[cardClipboard.ts](../apps/web/src/utils/cardClipboard.ts#L26)，关联 [AppV2.tsx](../apps/web/src/AppV2.tsx#L296)。

   剪贴板保存在模块变量中，卸载页面组件不会清空；退出和登录切换没有生产代码调用 `cardClipboard.clear()`。账户 A 复制私有卡片后退出，同一标签页登录账户 B，在 B 的可编辑任务粘贴，会发送 A 的标题、摘要和备注。建议在退出和身份切换时清空，并将剪贴板绑定当前用户。

   证据：模拟复现执行实际剪贴板、退出和粘贴回调，退出后仍能读取 A 的私有备注，之后实际调用 `createEntry('B-own-project', A 的内容)`。尚未做真实浏览器账户切换验证。

3. **[P1] Windows 停止脚本会结束其他项目的 Node 进程。**

   位置：[stop-team-server.ps1:16](../stop-team-server.ps1#L16)，关联 16–20 行。

   脚本枚举所有 `node.exe`，只要其可执行文件位于当前 Node 安装目录，就强制结束。多个项目通常共用同一个 Node 安装，因而执行该脚本也会结束其他开发服务器、任务或 Node 服务。建议启动时记录本项目进程身份，停止时限定这些进程及其子进程。

   证据：源码直接显示筛选条件仅为 Node 安装目录，没有项目或已启动进程的归属条件。未在 Windows 上执行。

4. **[P1] 清理 SQL 的账户删除没有限定测试工作区。**

   位置：压缩包中的 `apps/api/scripts/cleanup-verify-fixtures.sql`，32–38 行。该一次性维护脚本未执行，也未纳入本次 GitHub 发布。

   前半段按三个明确的工作区名称清理，后半段却在整个数据库中匹配 `username LIKE 'locktest%' OR username LIKE 'probe%'`，删除这些账户的会话、所有工作区成员关系和账户。真实账户只要具有相同前缀，即使不属于目标工作区，也会被命中；部分关联数据还可能使事务整体失败。建议采用明确的本轮测试用户 ID，并验证关联范围；不要从用户名的宽泛前缀推断可删除身份。

   证据：源码直接显示全库用户名条件，未引用 `cleanup_workspaces`。本次未执行该 SQL。

5. **[P2] 撤销移动会覆盖同事后续移动。**

   位置：[AppV2.tsx](../apps/web/src/AppV2.tsx#L589)，关联 589–602 行。

   自己把卡片从 10 月 1 日移到 2 日，同事随后移到 5 日。同步完成后撤销，代码取得同事最新的 revision，再将日期改回 1 日，因此服务端版本检查会成功，不能阻止覆盖。建议记录自己操作成功后的版本，并确认卡片仍处于该操作结果；已有后续修改时报告冲突。

   证据：模拟复现发送 `updateEntry('A', 'e1', { weekStartDate: '2026-10-01', expectedRevision: 3 })`，其中 revision 3 来自同事的 10 月 5 日版本。

6. **[P2] 撤销失败仍提示成功，且丢失重试机会。**

   位置：[AppV2.tsx](../apps/web/src/AppV2.tsx#L578)，关联 578–586、594–602、607–626 行。

   撤销先弹出记录，异步请求错误被吞掉，随后立即返回成功文案。例如粘贴后卡片被同事锁定，撤销删除被服务端拒绝，仍会显示“已撤销粘贴”，该记录也无法再次执行。移动和恢复删除存在相同处理。建议等待实际响应，统计成功与失败，保留失败项并明确提示。

   证据：模拟 API 返回 `409 entry_locked` 时，回调仍返回 `Undid paste of 1 cards`，且撤销栈已变为空。
