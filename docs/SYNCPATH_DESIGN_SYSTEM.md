# SyncPath 界面设计系统 v0.2

日期：2026-10-11。沿用灰白、炭灰与靛蓝品牌，目标是简约、直观、适合长时间规划工作的专业工具。历史品牌提取保留在 `SYNCPATH_BRAND_STYLE.md`；本文件描述当前实现。

## 1. 颜色与层次

唯一颜色源：`apps/web/src/index.css` 的 `--sp-*` 变量。组件和 Mermaid 预览消费这些变量；主题选择仍使用现有 light / dark / system 设置。

| 语义 | 浅色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| canvas | `#f4f5f8` | `#111214` | 页面与时间线底色 |
| surface | `#ffffff` | `#191b1f` | 任务卡片与普通面板 |
| raised | `#f9fafc` | `#202328` | 输入框、次级区域 |
| text | `#202635` | `#eff1f5` | 标题与核心信息 |
| secondary | `#465166` | `#c1c6d0` | 正文与次级说明 |
| muted | `#5d697e` | `#a0a8b6` | 日期、提示、元信息 |
| accent | `#6454d7` | `#b4acff` | 选中、链接、阶段节点 |
| accent-soft | `#f0edff` | `#29263b` | 选中背景 |
| border | `#d4dae5` | `#383e48` | 装饰性分隔与卡片轮廓 |
| control-border | `#808b9e` | `#707b8d` | 输入与可操作控件边界 |
| primary / text | `#252b38` / 白 | `#e2e4e9` / `#191b1f` | 一块区域的主要操作 |
| focus | `#6454d7` | `#ac9cfa` | 键盘焦点轮廓 |

暗色主按钮用浅灰反色，避免按钮与炭灰面板混成同一层。靛蓝集中用于选择和交互反馈。红色、绿色、琥珀色继续表达危险、成功和提醒。

## 2. 布局与字体

- 顶栏控件通常为 36px，登录输入为 44px；紧凑图标按钮保留文字可访问名称。
- 标题以 15–24px、600–650 字重为主；正文 13–14px，元信息 12px。减少全大写和宽字距。
- 工作台按「项目切换 → 任务列表 → 时间线」分层；任务名称、日期、可见性和当前角色可直接读取。
- 任务卡片使用 18px 圆角，按钮 10px，弹出菜单 14px，居中弹窗 22px。控制投影，依靠背景与边界表达层次。
- 复选操作独立于打开任务；选中卡片同时呈现靛蓝边框、浅色背景和明确勾选。
- 窄屏允许顶栏与底部工具换行；任务列表降为一列。时间线保留缩放和平移空间。
- 比较视图使用同一紧凑顶栏与 18px 外框；收到分享列表的进入按钮采用中性次操作，避免重复大色块。

## 3. 时间线

- 大节点：炭灰卡片与琥珀色标记；中节点：轻靛蓝卡片；细节：中性表面。
- 选择状态采用同一 focus 色；保留原来的选择 ring、拖动与键盘移动逻辑。
- 日期、摘要不再通过整张卡片降低透明度来表现过去时间，以保持内容可读。
- 时间轴日期与刻度字重减轻，字号提高；既有层级过滤、折叠、锁定、协作标记继续保留。
- Mermaid 预览从同一 CSS palette 取色，避免导出弹窗出现另一套深色样式。
- 长中文和英文节点标题按宽度换行，保留全文与转义保护；预览区域允许水平滚动。
- 白底 PNG 导出仅在克隆文档使用浅色配色；透明导出保留当前配色，两者均不改变用户正在使用的主题。

## 4. 弹窗与输入

- 背景遮罩 + 12px 背景模糊；弹窗 94–95% 表面不透明度与 24px 模糊，在阅读和毛玻璃质感之间取得平衡。
- 编辑、创建任务、分享、导出与确认弹窗使用统一表面；去掉编辑器和创建/分享弹窗的深色大标题栏。
- 侧边成员、项目/任务设置、历史面板消费同一表面与边界变量。
- 输入框使用 raised 表面，focus 轮廓与输入边框有明确变化。危险确认仍使用红色。
- 保留现有焦点管理、草稿、关闭确认、忙碌状态和保存冲突处理；本次视觉更新不修改其业务逻辑。

## 5. 验收标准与边界

1. 标题、正文、元信息、强调文字在 canvas / surface / raised / accent-soft 上的实体颜色对比度均 ≥4.5:1；控件边界相对 canvas / surface / raised ≥3:1。
2. 本次对实际 CSS token 计算 40 组组合：浅色正文最低 4.82:1，暗色正文最低 6.11:1；控件边界最低浅色 3.16:1、暗色 3.68:1；主按钮分别 14.18:1 / 13.55:1。
3. 浏览器检查工作台、时间线、选中卡片、编辑/创建/导出弹窗、比较页、收到分享、明暗切换、中英文和 390×844 窄屏；截图使用虚构数据，不访问业务正文。
4. Web 类型检查、109 项测试与生产构建通过；本次新增 4 项长标题/转义测试、3 项 PNG 克隆主题与下载流程测试，没有以静态 class 断言代替实际界面检查。构建仍存在部分 chunk 大于 500 KB 的体积提醒。
5. 上述对比度是明确 token 组合的计算结果，不代表所有遗留 utility、禁用状态、透明混色、第三方 SVG 或整个产品已满足完整无障碍标准。纯键盘新增/打开时间线卡片仍是审查待办。
6. App Store 包装、Windows/Electron、其他设备局域网连接不在本次视觉验收范围。

## 6. 后续维护

新增 UI 优先使用 `sp-app-shell`、`sp-topbar`、`sp-task-card`、`sp-button-primary/secondary`、`sp-icon-button`、`sp-popover`、`sp-dialog` 与 `sp-dialog-header`。现有 Tailwind 深色兼容规则是渐进迁移层；逐组件迁移后可以缩减，避免继续增加颜色字符串与覆盖优先级。
