从产品证据到团队交付

React 前端负责交互，API 负责授权与业务事务，Worker 执行耗时任务。数据库保存业务事实；模型结果先进入草稿。前后端独立构建，通过同源入口访问。

事实与草稿有明确边界

API 校验当前权限和对象版本后写入数据库。AI 结果保留来源、输入快照与模型版本，经用户采纳后成为正式内容。队列中的任务开始执行和发布结果时都重新检查权限。

按阶段引入基础设施

先完成 Web、API 和 PostgreSQL。Redis、Worker、对象存储在异步任务与附件阶段接入。图中合并数据库与附件存储；反向代理、观测和 CI 细节见开发计划。
